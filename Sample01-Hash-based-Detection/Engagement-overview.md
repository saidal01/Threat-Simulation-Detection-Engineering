# Task 1 - Introduction: Penetration Test

## Scenario

PicoSecure engaged in a purple team exercise to improve malware detection
capabilities. An external penetration tester (Sphinx) was tasked with
executing malware samples on a simulated workstation while the defender
configured security controls to detect and prevent malicious activity.

## Objective

- Analyze malware samples provided by the penetration tester.
- Identify unique indicators of compromise (IOCs).
- Create detection rules.
- Block malware execution.
- Increase adversary operational costs using the Pyramid of Pain framework.

## Initial Sample

Filename: sample1.exe

## Methodology

1. Submit sample to Malware Sandbox.
2. Review behavioral indicators.
3. Identify unique artifacts.
4. Create detection rule.
5. Validate prevention and detection.
